# Support conversations

Open Support, choose your report and tap **Xem trao đổi**. You can send follow-up
messages and load older history. Only the original reporter and active Admin/Staff
can access the thread; the other booking party cannot read your report.

A failed send retains its draft and retry ID while the screen stays mounted.
Sending a follow-up reopens a resolved report. Messages do not change the booking
or any cash declaration. Use **Tải lại trao đổi** to reload the thread; the existing
inbox announces staff replies while the app is active. No background push is added.

The Android bundle export validates compilation only. Native UI interaction has
not been tested on a physical device. API behavior and limitations are documented
in ../backend/SUPPORT_CONVERSATIONS.md.
